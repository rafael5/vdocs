Both are WAL/lifecycle bugs of the same family as P1.4.

cascade re-ran `index`, which rebuilt its tables with **identical row counts** — so `merge`'s cheap

live lake without being provoked, and it is also the P2 gate proving its worth: before P2 that
wipe would have shipped under a green pipeline, exactly the scenario the P2 prompt named.
